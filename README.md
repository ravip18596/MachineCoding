# MachineCoding
A collection of popular machine coding questions in python and golang for easy reference and interview preparations


| Track | Unique Questions Target | Why This Number Works | Your Current Priority |
| --- | --- | --- | --- |
| DSA | 60 – 80 (~5–7 per core pattern) | Covers all ~12 core patterns (Binary Search on Answer, Heaps/Greedy, Graphs/Topo/DSU, Sliding Window, Monotonic Stack, Trees, Intervals, DP) without diminishing returns. | Medium (`3.2/5.0` — focus on 1-pass dry runs before submitting). |

| Concurrency | 6 – 8 | Bounded Queue, Barrier, Read-Write Lock, Print in Order, FizzBuzz, Concurrent Crawler—all built on `Condition` or `Lock + Semaphore(0)`. | Highest (`2.0/5.0` — drill the 2 core patterns until automatic). |
